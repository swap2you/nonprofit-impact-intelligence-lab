# Data dictionary

`dim_*` tables hold stable reference entities. `fact_enrollment` contains monthly site enrollment; `fact_program_outcomes` contains attendance/completion outcomes; `fact_site_progress` contains milestones; `fact_funding_allocation` links synthetic funding sources to programs/sites; `fact_data_submission` records freshness and completeness; `fact_data_quality_issue` is the auditable issue ledger; `fact_migration_reconciliation` compares source/target keys.
